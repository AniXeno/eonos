# Security Policy

## Supported Versions

EonOS is a hobbyist operating system and only the **latest version** is actively supported with security fixes.

| Version | Supported |
| ------- | --------- |
| Latest  | :white_check_mark: |
| Older versions | :x: |

Older versions may still work, but they are not guaranteed to receive security updates or bug fixes.

## Reporting a Vulnerability

If you find a security vulnerability in EonOS, please report it by opening an **Issue** in this repository.

When creating the issue, please include:

- A short description of the vulnerability
- Steps to reproduce it
- The affected version
- Any relevant logs or error messages
- The potential impact, if known

Please avoid sharing sensitive information or fully weaponized exploit code in the issue.

As EonOS is a hobbyist project, response times may vary and there is no guaranteed response or resolution time. Security reports will be reviewed when possible and fixes may be included in a future release.
